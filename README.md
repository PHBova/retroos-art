# retroos-art

Arte dos jogos da página RetroOS · Backlog (hero, capa, logo e screenshots em WebP), servida pelo GitHub Pages.

Gerado por `scripts/retroos-art.mjs` do repositório `PHBova/clientes`. Não editar à mão: rodar o script e empurrar.

- `g/<jogo>-<sistema>/h.webp` hero, `c.webp` capa, `l.webp` logo, `s1..s3.webp` screenshots
- `index.json` o que cada jogo tem
